# Discord Clone

A full-stack communication platform inspired by Discord, built with **ASP.NET Core Web API** and a modern web frontend.

The project focuses primarily on backend development, including authentication, server and channel management, real-time messaging, video/voice calling, file attachments, and database management.

---

## 🚀 Features

### 🔐 Authentication & Security
* **User Registration & Login:** Secure authentication flow.
* **JWT-Based Authentication:** Token-based access control and authorization.
* **Password Hashing:** Industry-standard password hashing mechanisms.
* **Refresh Token Support:** Secure session persistence and renewal.

### 💬 Server & Channel Management
* **Server Creation & Management:** Create, customize, and manage servers.
* **Text, Voice & Video Channels:** Dedicated spaces for text messaging, voice communication, and video streaming.
* **Channel Access Control:** Granular permissions and channel visibility controls.

### 📹 Real-Time Communication & Video Meetings
* **Video & Camera Meetings:** Real-time video conferencing and camera-based communication.
* **Voice Calls:** High-quality voice channel connectivity.
* **Real-time Messaging:** Interactive real-time chat functionality.
* **Message Operations:** Edit and delete sent messages.
* **File & Image Attachments:** Share files, images, and media directly in channels.

### 🛡️ Administration & Operations
* **User & Member Management:** Role management and community moderation.
* **Admin Panel:** Complete oversight over server settings and user permissions.

### 🌐 API & Database
* **RESTful API:** Clean, structured, and predictable API architecture.
* **Swagger / OpenAPI Documentation:** Interactive API testing and interface documentation.
* **Entity Framework Core (Code First):** Database schema design and migration management.
* **MSSQL Database:** Robust relational storage for users, messages, and server structures.
* **FluentValidation:** Strongly-typed validation rules across API request payloads.
