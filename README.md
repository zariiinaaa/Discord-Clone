Discord Clone

A full-stack communication platform inspired by Discord, built with ASP.NET Core Web API and a modern web frontend.

The project focuses primarily on backend development, including authentication, server and channel management, messaging, file attachments, and database management.

Features
User registration and login
JWT-based authentication and authorization
Server creation and management
Text and voice channels
Channel access control
Real-time-style messaging functionality
Message editing and deletion
File and image attachments
User and member management
Admin panel functionality
RESTful API
Swagger / OpenAPI documentation
Entity Framework Core with Code First
MSSQL database
Password hashing
Refresh token support
